Architecture Overview

One Fortress, many Outposts — how the pieces fit together.

🏰
Backend Repo
Cloned with --filter=blob:none --no-checkout. Holds all Git objects (commits, trees) but materializes no blobs. HEAD is always detached — no branch is owned here, freeing all branches for worktrees.
📜
wt.yaml
Lives at the backend root. Defines worktrees_dir and a projects: map. Each project entry specifies branch, base, optional dir name, and sparse paths. This is the single source of truth for mwt add.
⛺
Worktrees
Each worktree is an isolated checkout: its own branch, its own files, its own terminal/editor state. Sparse checkout means only the declared paths materialize — everything else exists in the shared object store.
🔧
extensions.worktreeConfig
Set to true by mwt init. This Git config flag allows each worktree to have its own config.worktree file with independent sparse-checkout state, rather than sharing the backend's config.
