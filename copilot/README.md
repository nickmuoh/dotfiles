# GitHub Copilot CLI

This package manages GitHub Copilot CLI config under `~/.copilot/`.

## Install

- Repo: `https://github.com/github/gh-copilot`
- Installer: `curl -sSfL https://gh.io/copilot-install | bash`
- Bootstrap entry: `copilot|https://gh.io/copilot-install||bash`
- Dependency: `gh`

## Managed files

- `~/.copilot/settings.json`
- `~/.copilot/mcp-config.json`
