# zoxide setup

## Important configuration paths

- `~/.bashrc`

## Installed state

- Installed version: `0.9.9`
- Bash prepends `~/.local/bin` to `PATH`.
- Bash initializes zoxide only when `command -v zoxide >/dev/null 2>&1` succeeds.

## History-backed setup notes

- `curl -sSfL https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | sh`
- repeated `source ~/.bashrc` after setup
- history shows usage of `z` after installation

## Current state

- There is no separate zoxide config file currently documented in the home directory.
- Behavior comes from the default Bash init generated by `zoxide init bash` when the `zoxide` command is available.

## Caveats

- zoxide is only initialized for interactive Bash shells when `zoxide` is on `PATH`.
- Since there is no custom config file, changes to ranking behavior or exclusions would need to be introduced separately if you want them documented in the future.
